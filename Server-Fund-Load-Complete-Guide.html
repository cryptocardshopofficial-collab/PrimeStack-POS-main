Chapter 1 — Global Server Fund Load
PrimeStack Global Settlement Network (PGSN) — Real-Time Gross Settlement
ℹ
The Global Server is the primary correspondent network node. It sends large settlement batches to your platform via the PGSN protocol over TLS 1.3. Every load creates an immutable ledger entry. Minimum transfer: $10,000. Max per transaction: unlimited.

Step-by-Step in Dashboard
1
Log in → Platform → Server Funds → 🌐 Global Server tab
Admin dashboard at http://localhost:9006/login. Navigate to Platform → Server Funds.
2
Enter Amount and Currency
Type the agreed settlement amount. Select USD, EUR, GBP, AED, NGN, or KES. Use Quick Amount buttons for common values ($50K–$5M).
3
Enter Global Server Credentials
Host, Port, Node ID, and Auth Token from the global server operator. These are issued separately — keep them secret.
4
Set Source and Destination Accounts
Source: the account code on the global server (e.g. GLOBAL:RESERVE:USD). Destination: PLATFORM:RESERVE:USD for main reserve.
5
Enter Reference, Date, and Officer Name
Paste the global reference/transaction ID. Set settlement date. Enter the full name of the authorizing officer — this is recorded permanently.
6
Review Ledger Preview → Click Load
System shows DEBIT/CREDIT preview. Confirm amounts, then click 🌐 Load from Global Server. Entry is posted immediately and cannot be reversed without an audit entry.
7
Verify Balance
Go to Platform → Server Funds → 📊 Global Server Balance tab. Query PLATFORM:RESERVE:USD to confirm balance increased.

Chapter 3 — M1 Server Fund Load
M1 Private Banking Server — Institutional Correspondent Banking
ℹ
M1 Server is a dedicated private banking server for institutional transactions. It supports settlement transfers, liquidity injections, nostro account pulls, correspondent banking, and reserve replenishment. Minimum $10,000. Maximum $50,000,000 per transaction. Authenticated via API Key + Secret Token (HMAC-SHA512) + mTLS certificate.

Chapter 4 — M1 Funds Direct Transfer

⚠
Manual Process: M1 Funds Direct does NOT auto-pull from M1. The sender initiates the transfer on their M1 account and provides you with a confirmation number. You then record it in PrimeStack. Always verify the confirmation number against the actual M1 transaction before crediting.

Step-by-Step in Dashboard
1
Platform → Server Funds → 💰 M1 Funds tab
Admin dashboard → Platform → Server Funds → M1 Funds.
2
Enter Amount, Currency, Fund Type
Exact amount the sender transferred. Select currency. Select fund type (Wallet Transfer, ACH, Wire, Crypto).
3
Enter M1 Wallet ID and Account Holder Name
Wallet ID starts with M1W-. Account holder name must match M1 records exactly.
4
Enter Confirmation Number and Tx Hash
Paste M1 confirmation number (from sender's email/SMS). Add on-chain hash if crypto transfer.
5
Set Date, Time, Destination, Purpose
Transfer date and time from M1 confirmation. Destination account. Purpose of transfer for compliance records.
6
Enter Authorized By → Click Receive M1 Funds
Your name as the recording officer. Click 💰 Receive M1 Funds. Ledger entry posted: DEBIT M1:DIRECT:INCOMING → CREDIT destination.
7
Verify and Notify
Confirm balance in Ledger → Accounts. Notify sender that funds are received and credited. Keep M1 confirmation number for audit purposes.
✅
Compliance: Always retain the M1 confirmation number, sender wallet ID, and transfer date in your records. These are required for AML reporting and audit. All transactions above $10,000 USD equivalent are automatically flagged for compliance review.
