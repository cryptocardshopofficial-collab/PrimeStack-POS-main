sign-request.js — HMAC-SHA256 signing 
// Build the four required auth headers
import { createHmac, randomBytes } from 'crypto';

const signRequest = (keyId, secret, body = '') => {
  const timestamp = String(Date.now()); // 13-digit ms
  const nonce     = randomBytes(16).toString('hex');
  const payload   = keyId + timestamp + nonce + body;
  const signature = createHmac('sha256', secret)
                      .update(payload).digest('hex');
  return {
    'x-primestack-key-id':    keyId,
    'x-primestack-timestamp': timestamp,
    'x-primestack-nonce':     nonce,
    'x-primestack-signature': signature,
  };
};

// POST /t2t/transfer
const body = JSON.stringify({
  sourceId: 'TID-001', destId: 'TID-002',
  amount: '500.00',  currency: 'USD',
});
const headers = signRequest(KEY_ID, SECRET, body);
await fetch('https://api.primestack.io/t2t/transfer', {
  method: 'POST',
  headers: { ...headers, 'content-type': 'application/json',
             'x-primestack-idempotency-key': nonce },
  body,
});
Four required headers Every request carries x-primestack-key-id, x-primestack-timestamp, x-primestack-nonce, and x-primestack-signature. Missing any one returns 401.
Timestamp window The server rejects requests where the timestamp is more than ±5 minutes from server time. Synchronise your clock with NTP before signing.
Nonce replay protection Each nonce is stored on first use and rejected on replay. Use a cryptographically random 16–128 character alphanumeric string per request.
Idempotency key (T2T) T2T transfers require x-primestack-idempotency-key. The same key with the same parameters returns the original result without re-posting to the ledger.
Signature scope The HMAC is computed over keyId + timestamp + nonce + body. For GET requests body is an empty string. Use HMAC-SHA256 with the full secret.
