Integration Guide

Terminal-to-Terminal Transfer

Any external terminal from any country can send funds to your terminal. The external terminal is auto-created on the first transfer — no pre-registration needed.

1

Whitelist Sender IP

Before any transfer can happen, you add the sender's server IP to your whitelist via POST /t2t/whitelist. Only whitelisted IPs can push funds to you.

2

Sender Pings to Verify

The sender calls POST /t2t/ping from their server. Response confirms their IP is whitelisted and the connection is live.

3

External Terminal Auto-Created

When the sender calls POST /t2t/transfer, if their terminal ID doesn't exist, it's automatically registered. No pre-setup needed.

4

Ledger Entry Posted

Funds are debited from the sender's terminal account and credited to PST-001-PRIME via an immutable double-entry journal entry.

5

Transfer Completed

Reference, journal entry, new balance returned. Instant. No admin approval. Works from South Africa, UAE, UK, anywhere in the world.

Code Example

Complete Transfer in Node.js

t2t-transfer.js — sender runs this 
const crypto = require('crypto');

// Credentials you received from PrimeStack GSN
const SERVER  = 'https://primestack-global-server-network.onrender.com';
const KEY_ID  = 'psk_8c404d74df8344f6f3c27d767bc64694c7571fdf00d6e4da';
const SECRET  = 'YOUR_HMAC_SECRET'; // keep this private

// Step 1 — Build the transfer body
const body = {
  sourceId:    'SA-TERM-001',     // your terminal ID
  destId:      'PST-001-PRIME',   // receiver terminal
  amount:      '1000.00',
  currency:    'USD',
  description: 'Payment from South Africa',
};

// Step 2 — Sign with HMAC-SHA256
const bodyStr = JSON.stringify(body);
const ts      = Date.now().toString();
const sig     = crypto
  .createHmac('sha256', SECRET)
  .update(KEY_ID + ts + bodyStr)
  .digest('hex');

// Step 3 — Send the transfer
const res = await fetch(SERVER + '/t2t/transfer', {
  method: 'POST',
  headers: {
    'Content-Type':             'application/json',
    'x-primestack-key-id':      KEY_ID,
    'x-primestack-timestamp':   ts,
    'x-primestack-signature':    sig,
  },
  body: bodyStr,
});

const result = await res.json();
console.log(result.data.reference);  // TRF-XXXXX
console.log(result.data.status);     // COMPLETED
console.log(result.data.destBalance); // receiver new balance
