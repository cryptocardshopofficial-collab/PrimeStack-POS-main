Global Server Fund Load
Step-by-step procedure for loading settlement funds from an external global server into the PrimeStack platform reserve
ℹ
Global Server Fund Load records an inbound settlement from an external correspondent server or global network node. Every load creates an immutable double-entry ledger entry — debiting the incoming global account and crediting your platform reserve. No funds move without a valid reference and authorized officer.

03 — Step-by-Step Procedure
1
Log in to Admin Dashboard
Navigate to http://localhost:9006/login (or your production URL). Sign in with your admin credentials. Only SUPER_ADMIN and ADMIN roles can initiate fund loads.
2
Navigate to Server Funds
In the left sidebar go to Platform → Server Funds. Select the Global Server tab.
3
Enter Global Server Credentials
Enter the Global Server Host, Port, Node ID and API Key provided by your correspondent network. These are issued separately by the network operator.
4
Enter Amount and Reference
Enter the settlement amount, select currency, enter the global reference/transaction ID from the sending server, and the settlement date.
5
Enter Authorizing Officer Name
Enter the full name of the officer authorizing this load. This is recorded in the immutable audit log and cannot be changed after submission.
6
Review Ledger Preview
The system shows a preview of the double-entry: DEBIT on GLOBAL:SERVER:INCOMING and CREDIT on PLATFORM:RESERVE:USD. Confirm amounts are correct.
7
Click "Load from Global Server"
Submit the form. The platform posts the ledger entry in real time. The reference, timestamp, officer name and all details are recorded permanently.
8
Confirm Balance Updated
Navigate to Platform → Server Funds → Global Server Balance to confirm the platform reserve balance has increased by the loaded amount.

Compliance Note: Every fund load is subject to AML review. Loads above $10,000 USD equivalent are automatically flagged for compliance review. Ensure the global reference matches a verifiable transaction on the sending server before submitting.
